2. Flagship Subsystems

🧬 4-Operator Evolutionary Action Space

RSICraft separates mutation into four temperature-calibrated operators in rsicraft_core::operators: DRAFT (T=0.70, initial algorithmic diversity), IMPROVE (T=0.40, performance refactoring of a functional parent), DEBUG (T=0.20, deterministic stack-trace repair of broken cards), and CROSSOVER (T=0.50, hybrid recombination of two distinct high-utility parents).

📐 Composite Utility & Anti-Collapse Decay

Every experience card is scored by rsicraft_core::store::utility using U_i = 0.50 · s_norm + 0.35 · delta_norm + 0.15 · (1 / (1 + children_count)). Each time a parent is sampled to spawn a child, its children_count increments and its novelty bonus decays, naturally steering exploration toward under-sampled high-performing branches.

🖥️ Native egui 0.37 GPU Desktop Studio (rsicraft-app)

Renders an interactive Cubic Bezier Evolutionary Lineage DAG Canvas with animated pulse particles, an Evolutionary Score Trajectory Spark Chart with hover crosshairs, a 24 GB RTX 4090 VRAM allocation gauge, and the built-in 9-tab Tsinghua/OpenRSI dossier in high-contrast slate-950 dark or slate-50 light mode.

🛡 Air-Gapped Sandbox Evaluator (Docker / Python / Demo)

rsicraft_core::sandbox evaluates synthesized code in three selectable backends: hardened rootless Docker (--network none --memory 4g --cpus 4 --read-only --cap-drop ALL), isolated local Python 3.12 tempdirs with wall-clock timeout reaping, or a deterministic demo oracle.

5. Defense-in-Depth Safety & Containment Invariants

Five Non-Bypassable Guards Enforced Across rsicraft-core, rsicraft-mcp, and rsicraft-app:
  1. Compile-Time Zero-Panic Enforcement: Every crate declares #![deny(clippy::unwrap_used, clippy::expect_used, clippy::panic, clippy::todo, clippy::unimplemented)]. Malformed LLM outputs or crashing candidate scripts never crash the host engine.
  2. Air-Gapped Container Containment: Docker evaluation runs with --network none, --read-only root filesystem, --cap-drop ALL, --security-opt no-new-privileges, --pids-limit 64, and --memory 4g.
  3. Strict Wall-Clock Timeout Reaping: Both Docker and local Python 3.12 evaluators poll child processes on a 50 ms tick and forcibly kill any candidate exceeding timeout_secs, recording status TIMEOUT.
  4. BLAKE3 + Zstd Content-Addressable Integrity: Source artifacts are verified by 256-bit BLAKE3 digests and compressed with Zstd level 3 inside a transactional SQLite WAL store with PRAGMA foreign_keys = ON.
  5. Tofu-Free GPU Desktop Studio & Pure Stdio MCP: rsicraft-app locks source code against unrenderable Unicode dingbats via glyph_allowlist_no_tofu_chars, and rsicraft mcp emits 100% pure JSON-RPC 2.0 on stdout.
